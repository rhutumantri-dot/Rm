# Streamlit Starter

A minimal, working [Streamlit](https://streamlit.io) application scaffold.

## Getting started

```bash
pip install -r requirements.txt
streamlit run app.py
# open http://localhost:8501
```

## What's included

- `app.py` — the Streamlit app: sidebar controls, KPI metrics, a chart, a data
  table, and a CSV download button, all driven by a reproducible sample dataset.
- `requirements.txt` — pinned minimum versions for Streamlit, pandas, and numpy.
- `.gitignore` — common Python/Streamlit ignores.

Edit `app.py` to start building your own app.
